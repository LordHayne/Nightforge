Das Spiel zeigt ein Fehlerfenster

Alan Wake, 15.11.: Das Spiel öffnet ein Windows-Meldungsfenster, der Vorhang geht darunter, und der Spieler muss OK drücken, bevor Nightforge weitermacht. Seit jeder Start die Texte solcher Fenster mitschreibt, weiß Nightforge, was darin steht. Drei Wege, damit umzugehen. Lizenzen, Anmeldungen, eigene Launcher und jede echte Frage des Spiels bleiben in allen dreien beim Spieler.

Heute

Der Vorhang sinkt unter das Fenster. Zu sehen ist nur die Box des Spiels, englisch und technisch.

Der Spieler weiß nicht, dass Nightforge danach weitermacht. Mit dem Controller ist OK nur über den Zeiger zu erreichen, und das sagt niemand.

1 · Einordnen Empfehlung, zuerst

Die Box bleibt sichtbar, aber der Vorhang rahmt sie: oben, was los ist, darunter, was zu tun ist und dass Nightforge übernimmt. Unten steht, wie man mit dem Controller drückt.

EN: “The game reports an error” · “Press OK – Nightforge takes care of the rest.” · “Right stick moves the pointer” · “R2 clicks”

Braucht

Die Zeile über das Fenster lesen, während der Start läuft, nicht erst nach seinem Ende. Den Rahmen, den Steams Frage auf dem Vorhang schon hat.

Dagegen

Der Spieler drückt weiter selbst. Der Text der Box bleibt, wie das Spiel ihn schrieb.

ALAN WAKE
Noch ein Versuch, auf anderem Weg …
Das Spiel konnte sein Bild nicht aufbauen. Nightforge versucht es anders.
2 · Nightforge sagt es selbst

Die Box bleibt unter dem Vorhang. Nightforge sagt in eigenen Worten, was sie meldet, beendet das Spiel und macht weiter. Der Spieler drückt nichts.

EN: “One more try, another way …” · “The game couldn’t set up its picture. Nightforge tries another way.”

Braucht

Wie 1. Dazu: Der Vorhang bleibt über einem Meldungsfenster, obwohl er heute für jedes Fenster des Spiels sinkt. Nightforge beendet das Spiel selbst. Je bekannter Meldung ein eigener Satz in zwei Sprachen.

Dagegen

Nicht jede Box ist das Ende. „Dein Treiber ist veraltet“, OK, und das Spiel liefe weiter: Beendet Nightforge es dort, zerstört es einen Start, der gelungen wäre. Sicher ist das nur bei Meldungen, die Nightforge als Fehler kennt. Jede andere muss doch gezeigt werden.

ALAN WAKE
Noch ein Versuch, auf anderem Weg …
Nightforge hat die Meldung des Spiels für dich bestätigt.
Das Spiel meldete: „could not initialize your 3D graphics card“
3 · Nightforge drückt OK

Hat das Fenster genau einen Knopf, drückt Nightforge ihn. Das Spiel endet oder läuft weiter, wie es selbst will. Was es meldete, steht danach in seinen Worten auf dem Vorhang.

EN: “One more try, another way …” · “Nightforge confirmed the game’s message for you.” · “The game said: ‘…’”

Braucht

Ein kleines Hilfsprogramm in der Windows-Umgebung, das die Knöpfe des Fensters zählt und OK drückt. Von außen ginge es nur mit der Bedienungshilfen-Erlaubnis von macOS, und der mitgeschriebene Text nennt die Knöpfe nicht. Das Programm muss gebaut, signiert und mit der Engine verteilt werden.

Dagegen

Nightforge beantwortet ein Fenster für den Spieler. Eine Mitteilung, die er lesen sollte („Spielstand beschädigt“), wäre weg, stünde sie nicht danach auf dem Vorhang. Nie bei Spielen mit Anti-Cheat.

Vorschlag zur Reihenfolge: 1 sofort. 2 nur für Meldungen, die Nightforge sicher als Fehler kennt. 3 erst, wenn das Hilfsprogramm steht und an echten Spielen geprüft ist.
