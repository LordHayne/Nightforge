## Deutsch

Nightforge 0.3.5 macht den Start von Steam für Windows schneller und hält die Bildratensperre jetzt auch bei Spielen, die über D3DMetal laufen.

**Voraussetzung** wie bisher: ein Mac mit Apple silicon und macOS 26 (Tahoe) oder neuer.

### Steam für Windows
- **Schnellere Anmeldung auf Macs mit vielen Anschlüssen:** Auf einem MacBook Pro mit M5 Pro brauchte Steam für Windows bis zur Anmeldung 25–26 Sekunden, beim Start eines Spiels 37–45 Sekunden. Steam wartete auf ein Netzwerk, das es unter den vielen Anschlüssen des Macs nicht fand, und gab nach 20 Sekunden auf. Nightforge nennt Steam jetzt zuerst die Anschlüsse, die wirklich verbunden sind, und lässt unbenutzte weg. Auf diesem Mac meldet sich Steam nach 5–6 Sekunden an. [offen: andere Macs, mit Kabel]
- **Ein Spielstart startet Steam nicht mehr ein zweites Mal:** Beim ersten Spiel nach dem Öffnen von Nightforge startete Steam bisher zweimal, einmal ohne und einmal mit den Einstellungen des Spiels. Nightforge merkt sich jetzt, mit welchen Einstellungen ein Spiel zuletzt lief, und startet Steam gleich damit. [offen: Messung live, erwartet 10–15 Sekunden weniger]
- **Nach dem Update einmal neu:** Beim ersten Start von Steam nach dem Update beendet Nightforge die laufende Wine-Sitzung einmal und beginnt eine neue, damit die Änderungen oben greifen. Läuft gerade ein Spiel, wartet Nightforge damit.

### Bildrate
- **Die Sperre auf 60 FPS gilt jetzt auch bei D3DMetal:** Spiele, die über Apples D3DMetal laufen (etwa Black Myth: Wukong, Control, Hogwarts Legacy), liefen bisher ohne Sperre, auch wenn sie eingestellt war. Jetzt zeigt Nightforge dort ein Bild frühestens nach 1/60 Sekunde, wie schon bei DXMT und DXVK. Im Benchmark von Black Myth: Wukong hält sie 60 Bilder pro Sekunde, vorher waren es im Schnitt 201. Spiele mit Cheat-Schutz bleiben davon unberührt.

### Spielprofile
- **Die Spielprofile werden wieder jede Nacht aktualisiert:** Seit dem 20.11. scheiterte die nächtliche Aktualisierung, weil eine Quelle unsere Abfragen ablehnte. Nightforge fragt dort nicht mehr nach, neue und geänderte Profile kommen wieder an. [offen: erster grüner Nachtlauf auf main]

### Geplant für 0.3.5 [Platzhalter, noch nicht fertig]
- Ein ruhiger Ladebildschirm: ein Licht läuft die Naht im Nightforge-Logo entlang, ohne Texte über technische Schritte.
- Das Dock bleibt im Konsolenmodus ausgeblendet.
- Steams Fragen beim Spielstart lassen sich alle mit dem Controller beantworten, nicht nur die Lizenz.

### Bekannt
- **Spielwechsel bei laufendem Steam:** Brauchen zwei Spiele verschiedene Einstellungen, startet Steam beim Wechsel weiter einmal neu.
- **Andere Mac-Versionen im Fenster:** Mac-Versionen, die nicht mit Unity gebaut sind, können beim ersten Mal weiter in einem Fenster starten. Stell im Spiel einmal „Vollbild“ ein, das Spiel merkt es sich.
- Die bekannten Punkte aus 0.3.3 gelten weiter.

## English

Nightforge 0.3.5 makes Steam for Windows start faster and now applies the frame rate limit to games that run on D3DMetal as well.

**Requirements** as before: a Mac with Apple silicon and macOS 26 (Tahoe) or later.

### Steam for Windows
- **Faster sign-in on Macs with many ports:** on a MacBook Pro with M5 Pro, Steam for Windows took 25–26 seconds to sign in, 37–45 seconds when starting a game. Steam waited for a network it couldn't find among the Mac's many ports and gave up after 20 seconds. Nightforge now lists the ports that are actually connected first and leaves unused ones out. On that Mac, Steam signs in after 5–6 seconds. [offen: other Macs, with a cable]
- **A game start no longer starts Steam twice:** with the first game after opening Nightforge, Steam used to start twice, once without the game's settings and once with them. Nightforge now remembers the settings a game last ran with and starts Steam with them straight away. [offen: live measurement, expected 10–15 seconds less]
- **Once afresh after the update:** the first time Steam starts after the update, Nightforge ends the running Wine session once and begins a new one, so the changes above take effect. If a game is running, Nightforge waits.

### Frame rate
- **The 60 FPS limit now applies on D3DMetal too:** games that run on Apple's D3DMetal (such as Black Myth: Wukong, Control, Hogwarts Legacy) ran without the limit until now, even when it was set. Now Nightforge shows a frame there no sooner than 1/60 of a second after the last, as it already does on DXMT and DXVK. In the Black Myth: Wukong benchmark it holds 60 frames per second, where it averaged 201 before. Games with cheat protection are left as they are.

### Game profiles
- **Game profiles update every night again:** since 20 November the nightly update failed because one source turned our requests down. Nightforge no longer asks there, and new and changed profiles arrive again. [offen: first green nightly run on main]

### Planned for 0.3.5 [placeholder, not done yet]
- A calm loading screen: a light runs along the seam in the Nightforge logo, without text about technical steps.
- The Dock stays hidden in console mode.
- All of Steam's questions at a game start can be answered with the controller, not only the licence.

### Known
- **Switching games while Steam runs:** when two games need different settings, Steam still restarts once when you switch.
- **Other Mac versions in a window:** Mac versions not built with Unity may still start in a window the first time. Set "Fullscreen" in the game once; the game remembers it.
- The known points of 0.3.3 still apply.
