## Deutsch

Nightforge 0.3.4 behebt drei Dinge, die auf einem frisch eingerichteten Mac schiefgingen.

**Voraussetzung** wie bisher: ein Mac mit Apple silicon und macOS 26 (Tahoe) oder neuer.

### Rosetta
- **Nightforge fragt nach Rosetta, wo es fehlt:** Windows-Spiele brauchen Rosetta von Apple, und auf einem neuen Mac ist es noch nicht installiert. Bisher fragte Nightforge nur in der Ersteinrichtung danach. Wer sich zuerst über die Einstellungen bei seinen Launchern anmeldete, kam an dieser Frage vorbei, und danach starteten Steam für Windows und alle Windows-Spiele nicht. Jetzt fragt Nightforge, sobald die Bibliothek Spiele hat, und vor jedem Start eines Windows-Spiels. Nach der Installation geht es mit dem weiter, was du starten wolltest.
- **Eine Meldung, die sagt, was fehlt:** Statt „Ungültiger CPU-Typ im startfähigen Programm“ steht dort jetzt, dass Rosetta fehlt.
- Ein Start, der nur an fehlendem Rosetta scheitert, zählt nicht als Fehlstart des Spiels.

Warst du betroffen, fragt Nightforge nach dem Update beim nächsten Öffnen von selbst.

### Der erste Start
- **Mac-Versionen mit Unity starten im Vollbild:** Valheim kam auf einem frischen Mac beim ersten Mal in einem kleinen Fenster über dem Ladescreen. Unity-Spiele für den Mac starten jetzt beim ersten Mal im Vollbild. Was du später im Spiel einstellst, bleibt.
- **Mehr Geduld mit Steam:** Braucht Steam für Windows länger zum Starten, wartet Nightforge jetzt bis zu zwei Minuten, solange Steam vorankommt, statt es nach 45 Sekunden neu zu starten. Je Start gibt es höchstens einen Neustart von Steam.
- **„Hängt es? Zurück zu Nightforge“ kommt später:** erst, wenn Nightforge selbst nichts mehr tut, und nicht mehr, während es noch auf Steam wartet.
- **„Zurück zu Nightforge“ beendet den Start.** Bisher konnte das Spiel danach noch im Hintergrund starten.

### Bekannt
- **Steam startet auf einem neu eingerichteten Mac langsam:** Dort kann Steam für Windows deutlich länger brauchen als sonst, beim Wechsel von einer Mac-Version zu einem Windows-Spiel über eine Minute. Nightforge wartet darauf; woran es liegt, suchen wir noch.
- **Andere Mac-Versionen im Fenster:** Mac-Versionen, die nicht mit Unity gebaut sind, können beim ersten Mal weiter in einem Fenster starten. Stell im Spiel einmal „Vollbild“ ein, das Spiel merkt es sich.
- Die bekannten Punkte aus 0.3.3 gelten weiter.

## English

Nightforge 0.3.4 fixes three things that went wrong on a freshly set up Mac.

**Requirements** as before: a Mac with Apple silicon and macOS 26 (Tahoe) or later.

### Rosetta
- **Nightforge asks for Rosetta where it's missing:** Windows games need Rosetta from Apple, and a new Mac doesn't have it installed yet. Until now Nightforge only asked during the first setup. If you signed in to your launchers through Settings first, you passed that question by, and after that Steam for Windows and every Windows game failed to start. Now Nightforge asks as soon as your library has games, and before every start of a Windows game. After the install it goes on with what you wanted to start.
- **A message that says what's missing:** instead of "Bad CPU type in executable" it now says that Rosetta is missing.
- A start that only fails for want of Rosetta doesn't count as a failed start of the game.

If this happened to you, Nightforge asks by itself the next time you open it after the update.

### The first start
- **Unity Mac versions start in full screen:** on a fresh Mac, Valheim came up in a small window over the loading screen the first time. Unity games for Mac now start in full screen the first time. What you set in the game later stays.
- **More patience with Steam:** when Steam for Windows takes longer to start, Nightforge now waits up to two minutes while Steam comes along, instead of restarting it after 45 seconds. A start restarts Steam once at most.
- **"Stuck? Back to Nightforge" comes later:** only once Nightforge itself has nothing left to do, and no longer while it still waits for Steam.
- **"Back to Nightforge" ends the start.** Until now the game could still start in the background afterwards.

### Known
- **Steam starts slowly on a newly set up Mac:** there Steam for Windows can take much longer than usual, more than a minute when you switch from a Mac version to a Windows game. Nightforge waits for it; we're still looking for the cause.
- **Other Mac versions in a window:** Mac versions not built with Unity may still start in a window the first time. Set "Fullscreen" in the game once; the game remembers it.
- The known points of 0.3.3 still apply.
