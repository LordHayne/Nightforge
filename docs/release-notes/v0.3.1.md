## Deutsch

### Ein letztes Mal: die Frage nach dem Laufwerk
Nightforge ist ab 0.3.1 mit einer festen eigenen Signatur versehen, an der macOS die App über Updates hinweg
wiedererkennt. Nach diesem Update fragt macOS deshalb **noch einmal** nach dem Zugriff auf ein externes Laufwerk
(und, falls du sie erlaubt hattest, nach Bedienungshilfen oder Automation). Bitte erlauben: Danach behält macOS
deine Antwort bei jedem weiteren Update.

## English

### One last time: the question about your drive
From 0.3.1 on, Nightforge carries a fixed signature of its own, by which macOS recognises the app across updates.
So after this update macOS asks **once more** for access to an external drive (and, if you had allowed them, for
Accessibility or Automation). Please allow it: from then on macOS keeps your answer through every update.
